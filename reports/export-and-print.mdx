---
title: Export and print
description: Download a report as a CSV file or print it on Letter paper.
---

Only the Owner / Admin sees **Export CSV** and **Print**. Both buttons sit in the Reports header on the Today and Scoreboard lenses. They are not available on My hours.

<Frame>
  <img src="/images/reports/export-and-print.png" alt="The Reports header on Today with the lens tabs and the Refresh, Print, and Export CSV buttons" />
</Frame>

## Export CSV

<Steps>
  <Step title="Open Today or Scoreboard">
    On Scoreboard, pick the range you want first. A custom range can cover at most 366 days.
  </Step>
  <Step title="Click Export CSV">
    The browser downloads a file named bayboard-reports-[lens]-[from]-[to].csv.
  </Step>
  <Step title="Open the file">
    The file opens in Excel or Google Sheets.
  </Step>
</Steps>

The CSV has one section per tile on the lens. Job rows carry these columns: RO #, Customer, Vehicle, Tech, Job type, Hours, Status, Completed.

## Export one list from the drill panel

When you open the jobs behind a tile, bar, or segment, the drill panel shows a small download icon labeled **Export This List As CSV**. Click it to download only that list. The icon appears for the Owner / Admin only.

## Print

<Steps>
  <Step title="Open Today or Scoreboard">
    Set the range you want on Scoreboard.
  </Step>
  <Step title="Click Print">
    A print-ready page opens in a new tab, sized for Letter paper. The browser print dialog opens on its own.
  </Step>
  <Step title="Choose a printer or save as PDF">
    Use the print dialog as you normally would.
  </Step>
</Steps>

The printed page shows the lens title, the range, the shop name, "Generated [timestamp]", the metric strip, and the tables. An empty table reads "No matching records."
