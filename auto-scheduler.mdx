title: Auto-Scheduler

Every Auto-Schedule run reads the board and Unassigned.

It re-optimizes that day using the shop's existing hard constraints.

It also uses the shop's existing soft preferences.

Assigned and In Progress jobs can slide.

Time-off and no double-booking still hold.

Anything that does not fit stays in Unassigned.

The feature is deterministic. The same board, Unassigned, and settings always produce the same schedule.

A second run on those same inputs changes nothing.

The top-bar button reads **Auto Schedule**. You can also press S on the board.

## Who can run it

| Role | Run Auto-Schedule | Change scheduling preferences |
| --- | --- | --- |
| Owner / Admin | Yes | Yes |
| General Manager | Yes | Yes |
| Service Advisor | Yes | No |
| Foreman | No | No |
| Technician | No | No |

The button is hidden while billing is past due.

## How it decides

Auto-Schedule checks hard constraints first. A job is placed only where every one of these holds.

- Skill match. The technician can do this job type. An avoid list excludes them, except a job tagged "For" them.
- Parts received. A Waiting on Parts job places only when its parts ETA is today or earlier, and no earlier than the parts-ready hour.
- Respect time off. No job lands inside a time-off block.
- No double-booking. Two jobs cannot share one slot.
- Fits before end of day. The block must end by that weekday's shop closing time.

Jobs start on 30-minute marks inside shop hours.

Assigned and In Progress can slide.

Time-off and no double-booking still hold.

Soft preferences then decide which open slot wins. In the default order they are: Honor promised-by, Waiting customers first, Prefer the tagged technician, Best-qualified tech, Balance the board, Match pace to job, Earliest open slot. An Owner / Admin or General Manager can reorder or turn off any of them in Settings > Scheduling.
