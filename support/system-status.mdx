The System Status screen shows the live operational status of BayBoard services. It pulls from the public status page at [status.bayboard.io](https://status.bayboard.io).

## Open System Status

Click **Support** in the left rail, then **System Status**.

<Frame>
  <img src="/images/support/system-status.png" alt="The System Status screen with the headline state, last updated time, and per-service uptime bars" />
</Frame>

## What the screen shows

The headline at the top is one of four states:

- All services are online
- Some systems are experiencing issues
- Some systems are down
- Some systems are under maintenance

Under the headline, "Last updated on [date] at [time]" tells you how fresh the information is.

Each service has its own row with the service name, its uptime as "NN% uptime", and a 90-day bar that runs from "90 days ago" to "Today". Bar colors mean:

| Color | Meaning |
| --- | --- |
| Green | Operational |
| Amber | Degraded or maintenance |
| Red | Downtime |

Click **Status Page** to open [status.bayboard.io](https://status.bayboard.io) in a new browser tab.

## If the status cannot load

The screen shows "Can't load status" and "Open the public status page for the current state. This screen never assumes BayBoard is operational."

This screen never guesses that BayBoard is up. Click **Status Page** to check [status.bayboard.io](https://status.bayboard.io) directly.

## If the board is down

<Steps>
  <Step title="Check System Status">
    If the headline says systems are down or under maintenance, the BayBoard team already knows. Watch [status.bayboard.io](https://status.bayboard.io) for the latest status.
  </Step>
  <Step title="Contact Support if status looks fine">
    If all services show online but your board still will not load, send a ticket from [Contact Support](/support/contact-support). Set the Priority field to Urgent (board down) before you send.
  </Step>
</Steps>
