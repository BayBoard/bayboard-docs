BayBoard has a small set of shortcuts for the schedule board, moving between screens, and saving a job.

## Open the shortcut list

Press ? anywhere in the app. You can also click **Support** in the left rail, then **Shortcuts**, or open your account menu at the bottom of the rail and pick **Keyboard shortcuts**.

The overlay reads "Press [?] any time to bring this back."

The Shortcuts screen is titled "Keyboard Shortcuts" with the line "Fly through BayBoard without lifting off the keyboard." Shortcuts are grouped as Global, Schedule Board, Navigate, and Job Details / Add Job. Actions that change the board show a Confirm badge.

Shortcuts below use Ctrl on Windows and Cmd on Mac. Ctrl+K on Windows is Cmd+K on Mac.

## Global

| Keys | What it does |
| --- | --- |
| Ctrl+K | Search jobs / customers |
| Ctrl+J | Open Ask BayBoard |
| Ctrl+/ | Open Support |
| ? | Show keyboard shortcuts |
| Esc | Close any open modal |
| Ctrl+B | Toggle focus mode |

## Schedule board

| Keys | What it does |
| --- | --- |
| Left arrow / Right arrow | Previous or next open day |
| T | Jump to today |
| S | Run Auto-Scheduler (asks for confirmation) |
| C | Carry Forward uncompleted jobs (asks for confirmation) |
| R | Reset Day (asks for confirmation) |

## Navigate

These are chords. Press G, then the second key within one second.

| Keys | What it does |
| --- | --- |
| G then S | Go to Schedule |
| G then R | Go to Reports |
| G then H | Go to Support / Help |
| G then , | Go to Settings |

## Job Details / Add Job

| Keys | What it does |
| --- | --- |
| N | New Job |
| Ctrl+S | Save changes |
| Ctrl+Enter | Save & close |
| Esc | Cancel |

Both save shortcuts run the same save, which closes the drawer on success.

<Note>
Single-key shortcuts (T, S, C, R, N, ?, and the G chords) are off while you are typing in any field. Actions that change the board always ask for confirmation first.
</Note>
